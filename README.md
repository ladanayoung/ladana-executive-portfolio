## Hosting
GoDaddy domain is currently configured by the owner for Lovable. This repository is a separately deployable static copy. Do not point the same custom domain to GitHub Pages while it is attached to Lovable.

For a separate GitHub Pages preview, go to Settings → Pages → Deploy from a branch → main → /(root). GitHub publishes to the repository's default `github.io` URL. No CNAME file is included.
